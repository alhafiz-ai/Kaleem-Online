## Al-Danish Online Islamic & Arabic Academy

### 🌐 GitHub Pages Deployment Guide (گٹ ہب پر ویب سائٹ چلانے کا آسان طریقہ)

یہ ویب سائٹ گٹ ہب پیجز (GitHub Pages) اور گوگل کلاؤڈ / AI Studio دونوں کے لیے مکمل طور پر تیار اور ٹیسٹ شدہ ہے۔

گٹ ہب پر ویب سائٹ کو پبلش کرنے کے لیے آپ نیچے دیے گئے دو آسان طریقوں میں سے کوئی ایک طریقہ استعمال کر سکتے ہیں:

#### گٹ ہب پر ویب سائٹ چلانے کا طریقہ (GitHub Pages via GitHub Actions):
1. اپنے گٹ ہب ریپوزیٹری (Repository) پر جائیں۔
2. اوپر موجود **Settings** ٹیب پر کلک کریں۔
3. بائیں جانب مینو میں **Pages** پر کلک کریں۔
4. **Build and deployment** کے تحت **Source** میں **GitHub Actions** منتخب کریں۔
5. بس! اس پروجیکٹ میں پہلے سے `.github/workflows/deploy.yml` فائل موجود ہے۔ جیسے ہی آپ GitHub Actions منتخب کریں گے یا نیا کوڈ پش کریں گے، گٹ ہب خودکار طور پر ایپلیکیشن کو بلڈ کر کے لائیو کر دے گا۔
6. کچھ ہی سیکنڈز میں آپ کی ویب سائٹ `https://<your-username>.github.io/<repo-name>/` پر بغیر کسی خرابی کے کھل جائے گی۔

### 🔑 ایڈمن پینل (Admin Panel) تک رسائی
ویب سائٹ کے ایڈمن پینل کو کھولنے کے دو طریقے ہیں:
1. ویب سائٹ کے نیویگیشن بار میں موجود **لاگ ان / ایڈمن** بٹن دبائیں۔
2. یا براؤزر کے یو آر ایل کے آخر میں `#admin` لگائیں، جیسے:
   - `https://your-site.com/#admin`
